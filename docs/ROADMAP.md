# 第8–26项交付清单

生成、评分和语义验证调用用户配置的模型。测试响应仅存在于 `tests/`，没有离线产品模式。

| 项目          | 实现                                                          | 边界                                                       |
| ------------- | ------------------------------------------------------------- | ---------------------------------------------------------- |
| 8 面试前确认  | 能力、引用、资历、侧重点、时长、重要性校对                    | 确认后出题                                                 |
| 9 简历校对    | 模型结构化/手工分类，字符位置、PDF页码、确认                  | 文字修改使确认失效                                         |
| 10 覆盖规划   | 重要性分配、相邻能力轮换、相似题校验                          | 未问到与能力不足分开                                       |
| 11 停止条件   | 缺口、重复、跳过、时间预算、保护上限                          | 超时保留当前回答                                           |
| 12 训练任务   | 短板、完成标准、原报告证据、优先级                            | 计入历史反复出现程度                                       |
| 13 完成与掌握 | 勾选做过、新回答验收、换场景验证                              | 场景先确认，不直接比总分                                   |
| 14 趋势       | 资料、难度、问题、模型、量表条件分组                          | 改善与反复缺口可追溯                                       |
| 15 SQLite     | 持久化、搜索、重命名、删除、修订冲突、备份                    | 校验不是数字签名                                           |
| 16 请求恢复   | 请求ID、幂等、查询、取消、中断状态                            | 不承诺取消退费                                             |
| 17 多配置     | 档案、测试时间、重确认、系统凭据                              | 长期Key存储限Windows                                       |
| 18 真实验收   | 真实调用入口、完整步骤、配置时间记录                          | **缺实际账户，尚未执行供应商验收**                         |
| 19 Token成本  | 实际usage、未知状态、费率估算、相关原文上下文                 | 税费和缓存折扣未自动计算                                   |
| 20 隐私安全   | 脱敏、期限、删除导出、注入边界测试                            | 公网认证隔离属部署前条件                                   |
| 21 工程诊断   | 单元/API/浏览器测试、CI、格式、构建、请求诊断                 | 测试不证明评分质量                                         |
| 22 工作台     | 当前面试优先、压缩文案、错误焦点、手机布局                    | 验证桌面及360px布局                                        |
| 23 报告       | 打印/PDF含原文、位置、量表、复核、任务                        | 非单一分数图                                               |
| 24 OCR        | 扫描PDF/图片、延迟加载、识别后校对                            | 首次需下载语言包                                           |
| 25 语音/视频  | 中文、English、日本語；录音、摄像头预览、回放、转写校对后提交 | Web Speech、摄像头受浏览器限制；视频不上传；不推断情绪性格 |
| 26 交付       | 启动检查、端口、备份升级说明、单进程生产模式和 Docker         | 公网仍需私有隧道/认证；运行不依赖Skill/MCP                 |

最终测试记录见 `docs/VALIDATION.md`。真实供应商、扫描准确率和实际麦克风验收与测试替身结果明确区分。
