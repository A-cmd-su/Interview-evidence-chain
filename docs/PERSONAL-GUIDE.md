# 个人功能指南

## 模型分工

启动时会先显示“模型设置”。保存当前模型会自动建立并持久化默认配置档案；重启后先恢复模型地址、协议和模型 ID，再进入训练空间。展开“多个模型档案与真实供应商验收”可以另存其他档案。可为岗位提取、简历提取、出题、回答评分/追问、证据复核、等价场景、掌握度、语言表达分别选择档案。未指定的任务使用当前默认模型。

选择复核档案后，实际第二次请求会发送到该模型，报告记录真实复核地址与模型。选另一模型可能减少共享偏差，但不等于人工审查。界面列出资料接收方，必须勾选并保存确认；切换默认服务、修改分工或在新会话中使用已保存分工，需要重新确认。Windows 会把填写的 Key 保存到系统凭据管理器；Linux/macOS 只保存不含 Key 的配置，重启后需重新填写远程服务 Key。本机模型可不填 Key。

完整供应商验收入口发送公开合成材料并产生实际费用。矩阵记录精确配置的最新验收状态，最新失败会取代此前通过状态；记录只说明此配置在该时间完成流程，不证明专业评分准确。

## 预算与实际用量

在“历史与设置 → 单次面试预算与模型费率”填写各模型输入/输出每百万Token费率。所有费率使用所选统一币种，不自动换汇。填0关闭单次面试预算提醒。

出题及同一面试的各次评分计入该面试；独立资料提取、等价题生成各有请求组。调用前根据原文长度和输出上限估算预留，包含初评、复核，以及开启的掌握度/语言任务。预估超额、历史费用未知或费率缺失时，界面会先暂停发送；可取消，或明确仅本次继续。改变回答后必须重新预检。

实际费用使用供应商返回的usage与请求发生时费率计算。没有usage就显示未知，不用猜测的Token数量补齐账单。失败或取消可能已经计费，后续预算按未知处理。缓存折扣、税费和供应商特别计费未自动计算，预估不构成供应商硬预算。ASR可能按音频时长收费，单独确认，不混入文字Token预算。

## 资料与训练

训练空间可保存岗位JD、简历版本和经过校对的项目主张。主张绑定简历连续原文及字符位置，不能只凭名称生成经历。保存校对后的简历，后续选中同一原文时复用结果；保存岗位校对模板也可复用标签，但开始面试仍需确认本次设置。报告中的问题可收藏并再次练习。资料库最多300项，历史面试分页显示。

首次建议2天后验证短板，第一次不同场景的新回答通过后7天再测。至少两次间隔验证通过才记为稳定掌握，之后建议30天维护复测。重复场景、复制原回答、提前练习和勾选完成都不累计稳定次数；复测失败撤销稳定状态，需要重新积累证据。资料、模型或量表不同的记录不会硬合并为进步。模型条件改变时，趋势分组显示；旧任务的跨条件复测会列出未累计原因，可从新条件的面试报告建立训练起点。

## 语音、视频与语言练习

在面试准备页选择模式，并按需分别设置提问、回答、简历语言及目标练习等级。语言表达专项分析会额外调用配置的语言模型，只引用确认文字，反馈清晰度、用词和结构，不认证CEFR等级，不判断口音、情绪、性格或外貌。

设备预检不录制，最长30秒；回答录制最长180秒，支持回放和清理。浏览器自动转写需单独开启，音频可能交给浏览器供应商。也可以在“历史与设置 → 专用语音转写服务”选择凭据档案，填写完整的兼容`/audio/transcriptions`地址和ASR模型ID。

专用ASR每次都展示地址和模型，勾选上传确认后才发送音轨。视频画面不上传，单段音轨最多8MB。转写结果先进入校对区，点击“确认文字，填入回答”后才可评分。失败保留本地回放；页面提供请求ID恢复与取消。刷新后音视频Blob无法恢复，但已完成转写任务可查询并明确确认属于本题后填入。取消不能保证撤销费用。

报告提供快速复盘、分歧说明与详细证据。打印或另存PDF包含原文、偏移位置、量表、复核模型、训练任务与转写校对记录。
