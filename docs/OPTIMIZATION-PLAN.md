# 个人长期使用优化交付

2026-09-13：以下开发项已实现。模型输出始终来自所配置的在线服务，失败不使用离线评分或旧报告替代。测试供应商仅用于自动化测试。

| 项目         | 已交付行为                                                                | 验证与使用边界                                                                     |
| ------------ | ------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| 1 个人访问   | scrypt 密码、登录限流、注销与过期、HTTPS Cookie、全部资料接口鉴权         | 默认本机；远程须配置密码、HTTPS 来源与反向代理                                     |
| 2 可靠备份   | 每日工作区快照、30份轮转、校验导入、导入前备份、数据库检查                | 完整快照另含模型档案、费用配置、usage与密码摘要；Key不导出                         |
| 3 模式联动   | 文字/语音/视频、语言和难度贯穿出题、评分、追问、复测与报告                | 三种模式均以确认文字为评分依据                                                     |
| 4 设备预检   | 设备选择、音量、预览、回放、Esc停止、离开与迟到权限释放                   | 浏览器测试使用虚拟设备                                                             |
| 5 转写校对   | 原始转写与确认文字分别保留；评分只发送确认内容                            | 媒体留在当前页面，清理或离开后释放                                                 |
| 6 模型分工   | 岗位、简历、出题、评分/追问、独立复核、等价题、掌握度与语言任务分别选档案 | 分工或接收方改变后重新确认；无Key档案需会话解锁                                    |
| 7 预算       | 各模型费率、单次面试费用、发送前预留与超额确认、历史费率快照              | 根据实际usage估算；缺usage/费率为未知；不是供应商硬上限；ASR另计                   |
| 8 掌握度     | 未开始、已练习、待复测、未通过、新证据验证、稳定掌握；2/7/30天间隔        | 至少两次间隔的新场景、新回答通过；同题、提前练习、勾选不累计稳定掌握               |
| 9 个人资料   | 岗位模板、简历版本、带原文位置的项目主张、收藏题、搜索重命名移除          | 复用相同原文的确认资料；随备份导入与期限清理                                       |
| 10 语言与ASR | 提问/回答/简历语言、练习等级目标、引文式文字表达分析、专用ASR             | 中英日；兼容multipart audio/transcriptions；视频只上传音轨；每次另行确认上传与费用 |
| 11 报告      | 快速复盘、分歧与歧义、详细原文审计、转写校对及语言反馈进入打印/PDF        | 复核比例不是统计置信度，不做语言等级认证                                           |
| 12 性能运维  | 历史分页、按需加载报告/训练/设置；启动诊断；加密完整备份；发布准备与回滚  | 发布在新目录构建并恢复数据，验收后由操作者切换服务；不覆盖运行目录                 |

入口：训练空间的“个人资料库”“长期掌握度”，模型设置的“模型分工与接收方确认”，历史与设置的预算、转写与备份。使用与操作步骤见 [个人功能指南](PERSONAL-GUIDE.md)、[维护说明](OPERATIONS.md)。

实际账户、实体摄像头与麦克风、手机HTTPS、Docker引擎和公网域名仍需运行环境验收。开发测试通过不构成已完成公网部署或全部供应商兼容的声明。应用启动不依赖 Skill 或 MCP。
